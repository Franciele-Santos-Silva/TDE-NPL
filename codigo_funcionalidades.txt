==============================
1) src/data_loader.py
==============================

Função principal: load_dataset()

O que faz:
1. Lê dois arquivos CSV do diretório data/raw:
   - data/raw/Fake.csv
   - data/raw/True.csv
2. Cria uma coluna numérica de rótulo (label) para cada dataset:
   - Fake.csv -> label = 0
   - True.csv -> label = 1
3. Junta (concatena) os dois dataframes em um único dataframe.
4. Embaralha (shuffle) o dataset completo com random_state=42.
5. Limita o tamanho do dataset para no máximo 5000 amostras (n = min(len(df), 5000)).
6. Retorna um novo shuffle final com random_state=42.

Resultado esperado:
- Um pandas DataFrame contendo, no mínimo, colunas como:
  - text (texto da notícia)
  - label (0 = fake, 1 = verdadeira)


==============================
2) src/preprocess.py
==============================

Função principal: clean_text(text)

O que faz:
1. Converte a entrada para string.
2. Coloca o texto em minúsculas.
3. Remove URLs (padrão http\S+).
4. Remove pontuação usando string.punctuation.
5. Remove números (padrão \d+).
6. Remove excesso de espaços:
   - substitui sequências de whitespace por um único espaço
   - aplica strip() para remover espaços nas pontas
7. Retorna o texto limpo.

Função principal: preprocess_dataframe(df)

O que faz:
1. Cria/atualiza a coluna df["clean_text"] aplicando clean_text na coluna df["text"].
2. Define processed_path = "data/processed/cleaned_news.csv".
3. Se o arquivo já existir em data/processed/cleaned_news.csv, ele NÃO regrava e retorna df.
4. Se não existir, salva df em processed_path (CSV) e retorna df.

Resultado esperado:
- O dataframe passa a ter a coluna clean_text pronta para tokenização no BERT.
- O código evita reprocessar toda vez quando o cleaned_news.csv já existe.

4) src/train.py
==============================

Função principal: main()

Objetivo do script:
- Treinar um modelo BERT para classificação binária (fake vs true).
- Salvar o modelo e o tokenizer em models/bert.
- Salvar um split de teste preprocessado (data/processed/test_split.csv) para uso na avaliação.

Principais passos:
1. Inicializa execução:
   - print("Carregando dataset...")
   - ensure_dirs() para criar pastas necessárias
   - set_seed(42) para reprodutibilidade
2. Define caminhos e parâmetros:
   - model_dir = "models/bert"
   - test_split_path = "data/processed/test_split.csv"
3. Checagem de reexecução:
   - Se models/bert existir E test_split_path existir,
     o script imprime que vai pular o treinamento e retorna.
   (Ou seja, evita treinar novamente se os artefatos já foram gerados.)
4. Carrega dados e preprocessa:
   - df = load_dataset()  (lê Fake/True e aplica labels)
   - df = preprocess_dataframe(df) (cria clean_text e salva cleaned_news.csv se necessário)
5. Cria split de treino e teste:
   - Usa train_test_split com test_size=0.2 e random_state=42.
   - Divide:
     - textos: df["clean_text"]
     - labels: df["label"]
6. Salva somente o split de teste preprocessado:
   - Cria test_df com colunas:
     - clean_text
     - label
   - Salva em data/processed/test_split.csv
   Observação: isso é feito para manter o conjunto de teste fixo para avaliação.
7. Tokenização:
   - MODEL_NAME = "prajjwal1/bert-tiny"
   - tokenizer = BertTokenizer.from_pretrained(MODEL_NAME)
   - Tokeniza train_texts e test_texts com:
     - truncation=True
     - padding=True
     - max_length=256
8. Monta datasets no formato Hugging Face:
   - dataset de treino: input_ids, attention_mask, labels
   - dataset de teste: input_ids, attention_mask, labels
9. Carrega modelo:
   - model = BertForSequenceClassification.from_pretrained(MODEL_NAME, num_labels=2)
10. Define training_args:
   - output_dir="outputs"
   - num_train_epochs=1
   - per_device_train_batch_size=4
   - per_device_eval_batch_size=4
   - save_steps=500
   - logging_steps=100
   - seed=42
   - evaluation_strategy="no"
   Observação: evaluation_strategy="no" significa que não roda avaliação durante o treino.
11. Cria um Trainer e treina:
   - trainer = Trainer(model=model, args=training_args, train_dataset=train_dataset, eval_dataset=test_dataset)
   - trainer.train()
   Observação: mesmo com eval_dataset informado, a avaliação não é feita durante o treino por causa de evaluation_strategy="no".
12. Salva modelo e tokenizer:
   - model.save_pretrained("models/bert")
   - tokenizer.save_pretrained("models/bert")

Resultado esperado:
- models/bert/ com o modelo treinado e tokenizer
- data/processed/test_split.csv para avaliação futura

Resumo: o que o projeto “é” e “faz”
==============================

Este projeto implementa uma pipeline de detecção de fake news usando um modelo BERT para classificação binária.

Fluxo geral:
1. data_loader.py:
   - Carrega dados reais e falsos do Kaggle (CSV) e atribui labels (0/1).
2. preprocess.py:
   - Limpa os textos (remove URLs, pontuação, números; normaliza espaços e caixa).
   - Salva uma versão pré-processada para reaproveitar.
3. train.py:
   - Treina o BERT (prajjwal1/bert-tiny) por 1 época.
   - Cria split treino/teste com seed fixa.
   - Tokeniza com max_length=256.
   - Salva o modelo e o tokenizer.
   - Salva o split de teste preprocessado para avaliação consistente.
4. evaluate.py:
   - Usa o modelo treinado para prever o conjunto de teste fixo.
   - Calcula accuracy e classification report.
   - Salva previsões e matriz de confusão.
5. utils.py:
   - Garante existência de pastas para persistência dos artefatos.

Em termos práticos:
- Rodar src/train.py gera o modelo treinado em models/bert e prepara o test_split.csv.
- Rodar src/evaluate.py gera métricas e gráficos com base nesse modelo e no test_split.csv.
